# smart-skincare-recommendation-system
Machine learning based web application that predicts skin type and recommends personalized skincare products

Overview

The Smart Skincare Recommendation System is a machine learning based web application that predicts a user's skin type and recommends suitable skincare products based on their profile and skin concerns.

Features

* Skin type prediction using a machine learning model
* Personalized skincare product recommendations
* End-to-end ML pipeline with preprocessing and prediction
* Web interface built using Flask

Tech Stack

Python
Scikit-learn
Flask
Pandas
Machine Learning Pipeline

Machine Learning Model

The system uses a RandomForestClassifier with preprocessing steps including:

* StandardScaler for numerical features
* OneHotEncoder for categorical features

These components are combined into a machine learning pipeline for efficient training and prediction.

 Project Purpose
This project was developed as an academic project to explore machine learning pipelines, web integration, and recommendation systems.
